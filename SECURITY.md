# Security

This is a public repository. Treat every committed byte as public.

## Sensitive-data reports

If you believe a commit contains a secret, credential, private identifier, private topology detail, or other information that should not be public, do not reproduce the value in a public issue.

Use GitHub's private security-reporting path when available. If a private reporting path is not available, create only a minimal public issue stating that a private disclosure channel is needed; do not include the sensitive value.

## Publication controls

Pull requests run deterministic sanitization checks before publication. These checks are defense in depth and do not replace human editorial review.
